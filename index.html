사과데이 마음잇기 카드

나 전달법을 활용해 상대를 존중하는 사과문을 만들어 봅시다. 이 웹앱은 사과를 대신해 주는 도구가 아니라, 내 마음과 책임을 정리하도록 돕는 연습 도구입니다.

사용 전 약속
실제 친구 이름, 전화번호, 주소, 계정 아이디 같은 개인정보는 쓰지 않습니다. 마음이 불편하거나 심각한 갈등 상황이라면 혼자 해결하려 하지 말고 선생님과 먼저 상의합니다.

1. 카드 설정

존중 공감 책임 회복

실제로 전달할지, 연습용으로만 사용할지는 스스로 선택할 수 있습니다.

2. 나 전달법으로 내용 정리하기

예: 내가 네 말을 끊었다. / 장난으로 한 말 때문에 네가 기분 나빠했다.

예: 급한 마음이었다. / 장난이라고 생각했다. / 부끄럽고 당황했다.

예: 속상했을 것 같다. / 무시당한다고 느꼈을 것 같다. / 창피했을 것 같다.

예: 네 말을 끝까지 듣지 않았다. / 네 기분을 생각하지 않고 말했다.

예: 말하기 전에 상대 기분을 먼저 생각하겠다. / 네 말을 끝까지 듣
